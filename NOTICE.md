# NOTICE

`dsh-youtube-scroll` is an independent plugin, but it is built on the architecture and
design of **[dsh-bili-scroll](https://github.com/c1overzz/dsh-bili-scroll)** — an
MIT-licensed DSH plugin that scrolls Bilibili.

Parts of this project are adapted from it, in particular:

- the settings-page structure (host half + browser half + `settings.section` registration),
- the daily headless-round workflow (overlay profile → spawn `dsh` → one prompt → report file),
- the config / state / seen-file layout and the prompt style.

The upstream project is MIT-licensed. Its license text is reproduced below, as required.
